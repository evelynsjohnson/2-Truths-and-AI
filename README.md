# 2-Truths-and-AI

**Play Now:** [https://tinyurl.com/2truths-ai](https://tinyurl.com/2truths-ai)

## What Is It?
**2 Truths and AI** puts a modern twist on the classic "Two Truths and a Lie" game. Each round, players see three statements about one player:
- Two are **true facts** provided by that player
- One is a **convincing lie** generated by AI<br>

One random player each round becomes the **Chameleon** - their goal is to blend in and convince others to pick the wrong answer!

**Your mission:** Figure out which statement is the AI-generated lie!<br>


## How to Play
1. **Setup**: Choose players, rounds, and AI difficulty
2. **Enter Truths**: Each player privately writes two true facts about themselves
3. **Gameplay**: Each round, guess which statement is the AI-generated lie
4. **Score Points**: Earn points for correct guesses and for tricking others
5. **Win**: The player with the most points at the end wins!

## Key Features
- **Smart AI**: Multiple AI models with different difficulty levels
- **Customizable**: Adjust music, themes, and game settings
- **Game Stats**: See who was the best detective and best trickster
- **Accessible**: Designed for all players with clear visuals and navigation
- **Replayable**: Endless fun with different truths and AI-generated lies
